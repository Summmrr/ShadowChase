# ShadowChase
2D game written completely in java; no engine was used

Every step was created myself, including but not limited to:
 - Input Handling
 - Movement
 - Player/environment hitboxes
 - Collision Detection
 - Pause Menu
 - Graphics
 - All Interactions

To play game, simply download ShadowChase, open in any IDE supporting java, navigate to ShadowChase/main/ShadowChase.java and run the code.
